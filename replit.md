# JavaScript Practice Project

## Overview
A simple JavaScript practice file for learning and experimentation.

## Project Structure
- `javascript practice.js` - Main JavaScript practice file with callback examples
- `primer_project.txt` - Project notes in Spanish
- `src/` - Source directory with npm dependencies
  - `src/callback/callenge.js` - Callback challenge exercise
  - `src/package.json` - npm dependencies (xmlhttprequest)

## How to Run
Click the Run button or use the workflow to execute the JavaScript file with Node.js.

## Technology
- Node.js 20

## Dependencies
- xmlhttprequest (in src/)
